Dieses Programm zeichnet das gleiche Diagramm mit matplotlib. Es liest die CSV-Datei Zeile für Zeile ein – probiere aus, Spalten, Farben oder Beschriftungen zu ändern!


    

      
      
      
      
    

  







  

    

      
Hilfe & Bedienung

      
    

    

      

        
Daten laden

        
    
          
  • CSV öffnen lädt eine CSV-Datei, z. B. eine Messreihe aus dem Serial Plotter oder eine Umfrage. Datei auch einfach auf das Fenster ziehen. Trennzeichen ;, , oder Tabulator und deutsches Dezimalkomma werden automatisch erkannt.
    • 
          
  • Die erste Zeile mit Spaltennamen wird erkannt; fehlt sie, heißen die Spalten „Spalte 1“, „Spalte 2“ …
    • 
          
  • Beispieldaten lädt eine kleine Klassenumfrage zum Ausprobieren.
    • 
        

      

      

        
Diagramm wählen

        
    
          
  • Links einen Diagrammtyp antippen, darunter die Spalten einstellen.
    • 
          
  • Kategorie: eine Spalte mit Gruppen (z. B. Klasse) färbt Punkte ein bzw. bildet je Gruppe eine Säule, ein Kreisstück oder einen Boxplot.
    • 
          
  • Streudiagramm: Ausgleichsgerade mit Gleichung und R². Boxplot: Ausreißer-Regel und Werte beschriften. Histogramm: Klassenbreite und relative Häufigkeit.
    • 
        

      

      

        
Auswerten

        
    
          
  • Tabelle: die Rohdaten. Kennwerte: Median, Quartile, Mittelwert, Standardabweichung … (je Gruppe). Häufigkeiten: absolute, relative und kumulierte Häufigkeit.
    • 
          
  • Statistik-Tests: Signifikanztest (Binomialtest), t-Test für eine und zwei Stichproben mit p-Wert, Konfidenzintervall und Entscheidung.
    • 
          
  • Tabelle kopieren legt die gerade sichtbare Tabelle tabulatorgetrennt in die Zwischenablage – zum Einfügen in eine Tabellenkalkulation.
    • 
        

      

      

        
Weiterverwenden

        
    
          
  • PNG export / SVG export speichern das Diagramm als Bild (z. B. fürs Protokoll).
    • 
          
  • Als Python-Code zeigt ein Programm, das dasselbe Diagramm mit matplotlib zeichnet – zum Ausprobieren und Verändern.
    • 
        

      

      

        
Rechenregeln

        
    
          
  • Quartile wie im Schulbuch: Median der unteren bzw. oberen Hälfte, bei ungeradem n ohne den Median.
    • 
          
  • σ teilt durch n, s (wie „sx“ am Taschenrechner) durch n − 1.
    • 
          
  • Histogrammklassen sind halboffen [a; b), die letzte Klasse schließt das Maximum ein.
    •
